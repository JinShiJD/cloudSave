# Cloud_Save  

A network disk : code by qt5.14.2  

实现：登录、注册、加/删好友、和好友私聊/群聊、上传/下载/移动文件  

网络协议：Http  
数据库：MySQL/SQLite  
网络通信：Socket  
自定义：功能区分实现的协议  

具体：  
1、使用TCP/IP实现客户端服务端通信  
2、自定义应用层协议：设计PDU(protocol data unit)结构，包含消息总长度、消息类型、固定数据区(64字节)和可变数据区，用于封装所有的请求与响应  
3、粘包处理：先读unit长度字段，再读完整的PDU  
4、并发处理：利用qt的事件循环实现非阻塞I/O，单线程支持多客户端并发  
5、使用MySQL存储用户信息、好友信息  
6、文件传输使用分块上传/下载(每块4KB)，支持断点续传(通过记录已接收的字节数)
